# Sayın Hukuk Bürosu – Web Platformu

Sayın Hukuk Bürosu için geliştirilmiş; yüksek performanslı, SEO odaklı ve modern kurumsal web platformu.

---

## Teknolojik Mimari & Yetenekler

- **Framework:** Next.js (App Router, Server Components & Server Actions)
- **Programlama Dili:** TypeScript
- **Veritabanı & ORM:** Supabase PostgreSQL & Drizzle ORM (Tip Güvenli Veri Katmanı)
- **Arayüz & Tasarım:** Tailwind CSS
- **Kod Kalitesi:** ESLint, Prettier, Husky, lint-staged, GitHub Actions CI/CD Pipeline

---

## Temel Özellikler

- **Modern & Prestijli UI:** Hukuk bürosu konseptine özel tipografi, renk paleti ve duyarlı (responsive) tasarım.
- **Dinamik Hukuki Makaleler & Blog:** Supabase ve Drizzle ORM üzerinde çalışan dinamik içerik yönetimi.
- **Hizmet & Faaliyet Alanları:** Müvekkiller için kategorize edilmiş hukuki uzmanlık alanları vitrini.
- **İletişim & Danışmanlık Talebi:** Server Actions ile doğrulanmış ve doğrudan veritabanına işlenen form altyapısı.
- **Yüksek Performans & SEO:** Next.js Server Components mimarisi ile optimize edilmiş sayfa yükleme hızları.
